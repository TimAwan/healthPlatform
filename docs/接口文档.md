# 前后端联调接口文档

适用范围：第一期全部对外接口（经 Gateway 统一暴露）。内部接口（`/internal/**`，服务间调用，不走网关）不在本文档范围。

---

## 1. 通用约定

| 项 | 约定 |
|----|------|
| Base URL | `http://localhost:9000`（前端开发模式直接用相对路径 `/api/v1/...`，Vite 已代理到网关） |
| 认证方式 | 请求头 `Authorization: Bearer <accessToken>`；白名单接口除外（登录/验证码/刷新） |
| Content-Type | `application/json`（文件上传除外，用 `multipart/form-data`） |
| 统一响应 | `{"code": 200, "message": "success", "data": {...}}`；`code=200` 才算成功 |
| 分页请求 | Query 参数 `page`（默认 1）、`size`（默认 10，最大 100） |
| 分页响应 | `data: { total, page, size, list: [...] }` |
| ID 类型 | 后端 Long 序列化为**字符串**（雪花 ID 超出 JS 安全整数），前端按 string 处理 |
| 时间格式 | `yyyy-MM-dd HH:mm:ss` |
| 请求追踪 | 每个响应带 `X-Request-Id` 头，与后端日志对应 |

### 错误码

| code | 含义 | 前端处理 |
|------|------|----------|
| 200 | 成功 | — |
| 400001/400002/400003 | 参数校验失败 / 业务错误 / 请求体格式错误 | ElMessage 提示 message |
| 401001~401006 | 未登录 / Token 过期 / Token 无效 / 验证码错误 / 账号密码错误 / 登录锁定 | 清除本地登录态跳转登录页（401004/401005 刷新验证码） |
| 403001 | 无权限 | 提示即可 |
| 404001 / 405001 / 409001 / 500000 | 资源不存在 / 方法不支持 / 重复提交 / 系统异常 | 提示即可 |

## 2. 认证（auth-service）

| 方法 | 路径 | 说明 | 请求体 / 参数 | 返回 data |
|------|------|------|---------------|-----------|
| GET | `/api/v1/auth/captcha` | 获取图形验证码（5 分钟有效，一次性） | — | `{captchaId, image}`，image 为 `data:image/png;base64,...` 可直接给 `<img src>` |
| POST | `/api/v1/auth/login` | 登录 | `{username, password, captchaId, captchaCode}` | `{accessToken, refreshToken, tokenType:"Bearer", expiresIn}` |
| POST | `/api/v1/auth/refresh` | 刷新令牌（轮换，旧 refreshToken 失效） | `{refreshToken}` | 同上 |
| POST | `/api/v1/auth/logout` | 注销（需带 Authorization） | — | `null` |

> 连续输错密码 5 次锁定 10 分钟（返回 401006）。

## 3. 当前用户（system-service）

| 方法 | 路径 | 说明 | 返回 data |
|------|------|------|-----------|
| GET | `/api/v1/system/me` | 登录后获取个人信息、权限码、菜单树 | `{userId, username, realName, permissions: ["DOCTOR_VIEW",...], menus: [...]}` |

`menus` 节点：`{id, parentId, name, path, component, sort, status, children}`；目录节点 `component=null`。

## 4. 医生管理（doctor-service）

### 4.1 医生

| 方法 | 路径 | 权限码 | 说明 |
|------|------|--------|------|
| GET | `/api/v1/doctors` | DOCTOR_VIEW | 分页。Query：`page,size,keyword(姓名/手机号),auditStatus,hospitalId,departmentId` |
| GET | `/api/v1/doctors/{id}` | DOCTOR_VIEW | 详情（含医院/科室名、attachments） |
| POST | `/api/v1/doctors` | DOCTOR_CREATE | 新增（初始：待审核 + 下架 + 合作中） |
| PUT | `/api/v1/doctors/{id}` | DOCTOR_UPDATE | 编辑（已解约不可编辑） |
| POST | `/api/v1/doctors/{id}/approve` | DOCTOR_APPROVE | 审核通过 |
| POST | `/api/v1/doctors/{id}/reject` | DOCTOR_REJECT | 驳回，**reason 必填** |
| POST | `/api/v1/doctors/{id}/suspend` | DOCTOR_SUSPEND | 暂停，reason 必填；联动：医生及全部服务下架 |
| POST | `/api/v1/doctors/{id}/terminate` | DOCTOR_TERMINATE | 解约，reason 必填；联动：下架 + 合作状态终止 |
| POST | `/api/v1/doctors/{id}/resubmit` | DOCTOR_RESUBMIT | 已拒绝 → 重新提交（回到待审核） |
| POST | `/api/v1/doctors/{id}/on-shelf` | DOCTOR_ON_SHELF | 上架（仅 APPROVED 允许，否则 400002） |
| POST | `/api/v1/doctors/{id}/off-shelf` | DOCTOR_OFF_SHELF | 下架（联动全部服务下架） |
| GET | `/api/v1/doctors/{id}/audit-history` | DOCTOR_VIEW | 审核流水（按时间倒序） |

**医生创建/编辑请求体**（approve 可不带 body，其余审核接口 body 为 `{"reason": "..."}`）：

```json
{
  "name": "张三", "gender": "MALE", "phone": "13800138000",
  "avatarFileId": null,
  "hospitalId": "1", "departmentId": "101",
  "title": "主任医师", "specialty": "心血管疾病", "intro": "...",
  "attachments": [ { "fileId": "1948xxx", "fileType": "PRACTICE_LICENSE" } ]
}
```

**医生响应 data**（列表项与详情同构）：`{id, name, gender, phone, avatarFileId, hospitalId, hospitalName, departmentId, departmentName, title, specialty, intro, auditStatus, cooperationStatus, serviceStatus, createdAt, attachments[]}`

**审核流水项**：`{id, doctorId, fromStatus, toStatus, action, reason, operatorId, operatorName, createdAt}`

### 4.2 医生服务项目

| 方法 | 路径 | 权限码 | 说明 |
|------|------|--------|------|
| GET | `/api/v1/doctors/{doctorId}/services` | DOCTOR_SERVICE_VIEW | 该医生全部服务 |
| POST | `/api/v1/doctors/{doctorId}/services` | DOCTOR_SERVICE_CREATE | body `{name*, type, price, description}`，初始下架 |
| PUT | `/api/v1/doctors/{doctorId}/services/{itemId}` | DOCTOR_SERVICE_UPDATE | 同上 |
| POST | `/api/v1/doctors/{doctorId}/services/{itemId}/on-shelf` | DOCTOR_SERVICE_ON_SHELF | 前提：医生已审核通过且本人上架 |

## 8. 附录

### 8.1 枚举字典

| 枚举 | 取值 |
|------|------|
| 审核状态 auditStatus | PENDING_REVIEW 待审核 / APPROVED 已通过 / REJECTED 已拒绝 / SUSPENDED 已暂停 / TERMINATED 已解约 |
| 合作状态 cooperationStatus | ACTIVE 合作中 / TERMINATED 已终止 |
| 上下架 serviceStatus、服务状态 status | ON_SHELF 上架 / OFF_SHELF 下架 |
| 审核动作 action | APPROVE / REJECT / SUSPEND / TERMINATE / RESUBMIT |
| 附件类型 fileType | PRACTICE_LICENSE 执业证 / QUALIFICATION 资格证 |
| 启停状态 status | ENABLED / DISABLED |
| 性别 gender | MALE / FEMALE |

### 8.2 状态机速查

```
待审核 --通过/驳回--> 已通过 / 已拒绝
已拒绝 --重新提交--> 待审核
已通过 --暂停/解约--> 已暂停 / 已解约
```
非法转换返回 400002；SUSPENDED 无流出转换（业务待定）。

### 8.3 联调最小链路（curl 示例）

```bash
# 1. 验证码（取 image 人工识别，或先跑前端页面）
curl http://localhost:9000/api/v1/auth/captcha

# 2. 登录（替换 captchaId / captchaCode）
curl -X POST http://localhost:9000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"Admin@123456","captchaId":"xxx","captchaCode":"abcd"}'
# → 取 data.accessToken 记为 $TOKEN

# 3. 当前用户（权限 + 菜单）
curl http://localhost:9000/api/v1/system/me -H "Authorization: Bearer $TOKEN"

# 4. 新增医院 → 科室 → 医生 → 审核
curl -X POST http://localhost:9000/api/v1/hospitals -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" -d '{"name":"市第一人民医院","code":"H0001"}'
curl -X POST http://localhost:9000/api/v1/departments -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" -d '{"hospitalId":1,"name":"心血管内科","code":"D001"}'
curl -X POST http://localhost:9000/api/v1/doctors -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"张三","gender":"MALE","phone":"13800138000","hospitalId":1,"departmentId":1,"title":"主任医师"}'
curl -X POST http://localhost:9000/api/v1/doctors/{id}/approve -H "Authorization: Bearer $TOKEN"

# 5. 列表 & 越权验证（换一个只有 DOCTOR_VIEW 的 token 调审核接口 → 403001）
curl "http://localhost:9000/api/v1/doctors?page=1&size=10" -H "Authorization: Bearer $TOKEN"
```
